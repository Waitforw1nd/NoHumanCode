# Sprint 05 · 多 Agent 并行检索与编排

## S5-T1 · 在一次对话里并行回答多个代码问题

起点为 [Baseline 5](../BASELINE-CHANGELOG.md)。例如用户问“访问令牌在哪里刷新，哪些测试证明工具不会重复执行”，主会话可让两个只读子请求分别搜索 `src/` 和 `tests/`。主会话拿到两组带路径和行号的依据，再给用户一个答案。

### 工具与结果

- 主会话可调用批量工具 `explore_parallel`。一次接收 1–4 个分支，每项含问题 `question`、工作区相对目录 `path` 和字面检索词 `query`。现有 `explore_files(question, paths)` 继续服务于已知文件的请求和已有会话。
- Host 先校验整批目录和读取权限，与 `search_files` 共用目录遍历、忽略规则及文本读取，对本支命中行提取上下文。每支最多选 4 个文件，按路径和行号合并相邻命中及各一行上下文，编号摘录总计最多 40 KiB。单支遍历超过 100,000 个目录项时，返回缩小目录范围的提示。零命中直接返回空结果。每个子模型仅接收自己的问题和摘录，工具列表为空。[工作区检索](../../src/workspace.rs) · [并行检索与摘录](../../src/workspace/parallel_exploration.rs)
- 父任务协调分支，在现有模型对话中汇总，无需额外发起一次汇总模型请求。工具结果按输入序号返回每支的状态、摘要和证据位置。进度可以按完成先后显示在标准错误上，保证管道标准输出仍是父会话正文。

### 调度与记账

当前父任务在工具循环期间已经占有一个全局并发名额，单次探索沿用这个名额。每批最多同时运行两支，一支复用父任务名额，第二支仅在能立即取得额外全局名额时启动。名额已满时由第一支继续处理队列。每次实际发送仍走 `complete_route` 的凭据并发限制、KeyPool、网络授权、预算预留与回执结算。[父任务调度](../../src/engine.rs) · [模型发送路径](../../src/engine/key_pool.rs)

子请求返回摘要或错误及已取得的用量，由父任务更新用量并按输入顺序写入一次工具结果。单支无命中或读取失败时保留其他分支证据。父任务取消、授权撤销或预算拒绝时停止新派发，已发送请求按各自回执结算。重启后沿用现有探索的中断提示，避免自动重放可能已计费的分支。[现有摘要与用量处理](../../src/engine/exploration.rs) · [中断提示](../../src/tool_results.rs)

## S5-T2

### 独立子任务与重启恢复

SQLite v19 将每个分支的检索参数、结果、证据和序号独立落盘。批次归属项目、工作区、会话及父任务。同一工具调用重放返回原批次；独立提交使用会话内的 `--key`。相同键对应不同输入时报告冲突。v18 的已有会话及工具历史保留原来的恢复语义。[存储与迁移](../../src/exploration_jobs.rs)

每次实际模型发送在网络准入和预算预留的同一事务中绑定子任务及尝试。重开数据库时，已完成和无命中分支保留结果；未保存结果的运行中分支按发送回执恢复。可以确认未发送时回到队列；请求可能已到达上游时显示 `unknown` 和回执，包括已结算却缺摘要的情况。只有显式 `retry` 会开启一次新尝试。父任务按原序写入工具结果，并附上 `batch_id` 和各分支的 `job_id`。[网络准入](../../src/network_authorization.rs) · [探索执行](../../src/engine/exploration.rs)

### 让下一批使用前批结果

每支可在 `depends_on` 提供至多 32 个不同的前置子任务 ID。提交事务只接受同一项目、工作区和会话内较早批次的 ID。前置成功或无命中即满足依赖；失败、取消或结果未知只影响引用该支的任务。继续一个子任务或批次时，运行中的 CLI 会先推进所需前置，再把已保存的摘要和证据交给后续子模型。同步 `explore_parallel` 同样支持这个字段。[用户示例](../../README.md#继续上次的探索或让下一批使用已保存的证据)

在会话中可用 `/jobs list`、`/jobs show ID`、`/jobs submit KEY FILE`、`/jobs continue ID` 和 `/jobs retry JOB_ID`。脚本可用 `coda --json jobs --session SESSION` 加相应子命令。独立提交先返回 ID；执行由运行中的 CLI 或父任务驱动，无后台守护进程。[CLI 入口](../../src/cli/jobs.rs)
