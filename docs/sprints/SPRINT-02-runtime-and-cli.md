## 交付记录

- **MCP**。同一 Engine 按会话、工作区和服务配置复用进程与工具定义。池上限为 32，满时淘汰空闲连接。配置变更和断线后可重建连接。工具已派发时若取消或失去响应，任务保留“执行结果未知”，恢复时返回对应审批 ID，避免重复执行。公共 `call_tool` 兼容只提供调用的服务。单个候选服务忽略工具列表请求时，客户端重新握手，再按原名派发一次。
- **上游请求**。推理、模型列表、路由检查和余额查询收到 429、502、503、504 时最多重试两次。默认退避 250 ms、500 ms，支持秒数或 HTTP 日期形式的 `Retry-After`，服务端要求等待超过 10 秒即返回该次错误。每次发送重新检查授权、单独登记回执，推理请求重新核算预算。成功响应开始后的断流直接交回调用方处理。
- **CLI**。原命令入口拆为 `mod.rs`、`init_route.rs`、`repl.rs`、`mentions.rs`、`http_admin.rs`。逐项比对拆分前后 81 个命令路径的 `--help`，标准输出、标准错误与退出码均一致。
