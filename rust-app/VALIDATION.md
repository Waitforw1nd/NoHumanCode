# Rust 0.2.0 验收记录

日期：2026-09-20。环境：Windows x64，Rust stable 1.98.1。

## 本地自动验证

- 10 个库测试、8 个运行时集成测试通过，包含 WASM manifest/ABI、Agent `run_wasm` 边界、`Idempotency-Key` 重复提交和 v1→v2 schema 迁移；在线付费测试保持忽略。
- Clippy 全目标检查通过，启用 `-D warnings`。
- Release 构建通过，产物复制到 `D:\peachsh-harness\bin\peachsh.exe`。
- 启动检查通过；重复使用同一数据目录启动时正确拒绝，避免覆盖运行状态。
- 浏览器访问确认后端报告 `runtime: rust`、版本 `0.2.0`；当前正式实例健康接口返回 `schema_version: 2`。
- `/api/wasm/plugins` 路由启动后可用，当前项目没有安装插件时返回空列表，不会影响普通任务。

通过显式开启的 Rust 集成测试完成，Key 仅从临时进程环境获取，未保存到应用设置。

| 测试 | 结果 |
|---|---|

| 两模型并行流式计算 17 × 19 | 都返回 323 |

首次文件工具实测遇到流连接中断。调整为收到 `[DONE]` 后立即结束读取，避免依赖上游关闭连接；重测全链路通过，并添加了“上游发完 DONE 但保持连接”的回归测试。该实测不代表第三方接口将来不会波动。

## 浏览器完整流程（隔离模拟环境）

使用独立数据目录和本机模拟接口，不修改正式账号：

1. 新建任务并添加两个成员，分别选择两个模型路由。
2. 确认两个成员的流式结果完成，自动汇总成员在前置完成后生成结果。
3. 继续第二个成员，确认第二步完成并保留原名称、角色和模型。
4. 绑定模拟 New API 账号，展示余额 5、已用 1；令牌字段在成功后清空。
5. 验证窄窗口布局；补齐新建任务与历史入口。

正式 New API 账号尚未绑定，没有把模拟余额当作真实账户余额。
