## 每轮更新约定

1. 开始时核对身份与最新任务是否仍一致；任务有变化就先更新身份。
2. 实现、review 或决策产生实质变化后及时保存，避免等对话耗尽才补写。
3. 结束时写本轮报告或 review，并刷新身份中的证据链接、状态、待办和恢复第一步。没有测试就写“未运行，原因……”；没有当前任务就写“待派发”。
4. 经理维护总进度、对话记录及审查台账；员工不得自行将“提交待审”改成“已验收”。
5. 新员工从 [身份模板](模板/个人身份认知模板.md) 建档；任务、报告和 review 使用本目录模板。
