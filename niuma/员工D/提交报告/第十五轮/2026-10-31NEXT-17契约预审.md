# NEXT-17 chat-agent 策略边界独立预审

日期：2026-10-31；员工D / 6.1 Terra。主仓只读观察 HEAD `6f22e4f8ca3356e24855962a517912cfc9ecc93b`；阅读经理 NEXT-16 后架构矩阵、`run_task`、ProviderRuntime、ToolRuntime、审批与工具历史校验。本轮没有运行代码或测试，以下是设计风险和验收提案，不是已复现缺陷或新产品派工。

## 权威边界与替换含义

策略可读取 Host 限定的不可变上下文快照并提出有界下一步候选；不持 Store、Engine、凭据、ProviderPermit、ToolLease、审批能力或可写 Task。Host保留 Project/Session/Turn/Task 身份及权限版本、消息和工具结果权威、最大轮次/取消、Provider 网络和预算 claim/finish、审批/工具执行、消息提交、终态与恢复。候选的快照版本、generation、动作形状和权限在使用前核验；不接受策略伪造 assistant/tool 消息、改写历史、将无凭证结果标为成功或直接要求批准。

真实替换意味着在同一 Host、同一受控 Provider/任务下，替换绑定可观察地改变下一步选择（例如一个策略请求一次模型、另一个在允许的显式终止条件下结束），而网络/预算/审批/结果事实仍由 Host产生。以注册名变化、只改展示或 Host 忽略策略输出冒充替换均不够；不应为了构造可观察差异开放任意内容写入或绕过模型返回校验。具体终止条件及消息来源须经理冻结，策略“建议结束”本身不能伪造完成。

## 反例与验收建议

1. **历史与权限**：测试策略要求修改历史、跨 Project/Task、替换模型/凭据/路径、注入 tool-result、跳过审批或用已有结果 ID 冒充新完成；检查持久快照/事件/文件不变，网络与审批/工具 claim 数为零，错误固定且不含秘密。所有允许动作对照必须经过真实 Engine、Store、ProviderRuntime/ToolRuntime；不能仅测孤立 trait。
2. **进度与工具组**：恶意或有缺陷策略重复相同候选、空候选、重复调用 ID、复用历史 ID、缺函数名/畸形 JSON、未授权工具、同组前合法写后非法调用；用严格调用/事件上限及超时证明停止且无无限 loop。现有 `validate_new_tool_group` 先检查 ID，名称/参数及授权随后逐项执行；若要求“任一非法时整组零副作用”，这是须明定并实现的更强契约，不能把现状视为已保证。使用两个受控写入对照证明先整组验证、后执行，并保留按次审批和实际回执。
B 独立只读反馈同意：沿兼容路径保留原顺序及逐项 Host 校验；策略若拒绝，Host 生成固定拒绝结果不得冒充实际执行回执。整组原子拒绝应作为显式语义变更，单列迁移及历史回归。具体如何结束或继续仍须冻结。

3. **禁用与过期**：屏障固定策略快照→策略disable/re-enable→候选提交交错，旧generation须拒绝新准入；准入先赢时策略 lease 的结果如何使用需明确线性化点。分别在 Provider 已claim、工具审批等待、工具已claim 后禁用策略/Provider/工具：无对应 lease 的新调用拒绝，已经准入者按各自合同完成或取消并结算；已发生效果不能宣称撤销。断言每条 receipt、budget held、审批消费次数和实际模型/工具命中，不以状态位代替效果。
4. **失败和重启**：策略构造/决策/析构 panic 与错误中植入合成秘密，子进程捕获日志与事件，证明受保护回调不泄漏，普通非回调 panic 仍输出；故障未claim不产生账本，已claim必须进入原 finish/unknown 路径。真实进程分别在候选产生前后、网络claim/finish、审批/工具claim及持久提交边界 kill+wait，再用新Host重启同库两次，核对身份、旧消息不可改、unknown/预算占用、已批准结果与实际外部命中次数不自动重放。若用户明确恢复后重试，须生成新受控动作及回执，不能把不确定旧效果改为成功。
5. **锁与取消**：策略回调/析构不得在 Engine gate、策略/Provider/Tool runtime 或 Store 锁内执行；跨runtime不得嵌套锁，沿 gate→单runtime→短同步Store准入，释放后才 await/执行回调。用同步屏障固定禁用、准入、Drop重入状态查询与取消/错误返回，采用有界超时，证明无死锁、lease计数归零且无claim丢失。现有 ToolRuntime 的 definitions/service 回调发生于其锁内；应审计实际调用链并限定本切片可承诺的锁序，不把拟议规则误述为现有全局事实。

设计限制：可信进程内 Rust 策略不是恶意本机插件沙箱；接口隔离仍需防止意外越权与错误输出。上述反例需正式任务、唯一文件所有权、版本化接口与测试调度后实施；D当前仅预审，无产品写权。完整项目和默认组合仍未完成。
