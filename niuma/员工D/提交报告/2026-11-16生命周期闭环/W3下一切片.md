# W3 下一切片依赖与差距

2026-11-16，D；静态核对基线 668c6b89 与本轮 B 的接口消息，不是 W3 实施/验收。W2 已验收组件继续复用，公开 `run_wasm` 拒绝门保持。参考旧 C29 工件预审、C26 恢复设计及现行经理闭环任务；其中历史暂停和旧 schema 数字不能覆盖本轮授权与实际代码。

| 层次 | 当前可复用入口 | 生产绑定差距 | 下一切片直接验收 |
| --- | --- | --- | --- |
| 数据域执行权 | B 本轮实际 file identity/pin/OS mutex、共享在途票、Engine 关闭接口；首切片维持 schema17 | 全 U/schema18、所有恢复/迟到结果事务 fence 尚不能视为完成；W2 尚未消费同一域能力 | 同库两个 Store/Host、别名、`--check`、在途取消/关闭、已收束普通失败可再工作；未知封门，旧结果不得重新派发 |
| 固定 worker 字节 | `wasm_worker_process.rs` 的 `TrustedWorker {path,digest}`、`Image::pin`、`WorkerService::from_trusted`（crate 内部） | 构造仍有 “installation boundary connected later” 注释；`main`/composition 没有正式安装引导 | 受信 Host bootstrap 固定同包文件名与预期摘要；缺失/错 hash/旧协议/工作目录变化均失败关闭；不能从业务或运行时 env 收任意 exe/hash |
| 成对工件 | `build.ps1` 从当次 Cargo artifact 选择 Host；D runner 固定源码/日志 | 目前 build 只发布 Host，没有 worker→冻结副本→Host 摘要的成对构建链 | 先 worker、独立副本取 hash、仅 Host binary 编译期嵌入、再 Host；同 profile/target/feature/源码。修改 worker 必须更新 Host；混搭、半包、后续 target 重建不能误认证 |
| 协议及策略输入 | `wasm_worker_protocol::Manifest` 已有 version/request_id/nonce/binding_generation/plugin_id/plugin_version/digest/fuel/memory_pages；W1/W2 校验有界输入输出 | 回显 manifest 不是二进制信任；插件持久 binding generation 与实际配对工件未连线 | 错 nonce/generation/digest/phase、重复响应、跨请求响应不得采纳；Host 保留最终权限裁决，worker 无权扩大工具权限 |
| 创建、恢复及清理 | W2 创建时 Job 归属、原对象与有限 I/O；当前未知保守语义 | 内存 handle、PID、epoch 或拿到新 owner 都不是跨崩溃旧 worker 已退出证明；creating/registered/结果采纳持久链未完成 | 创建/登记/结果提交各停点真实崩溃，旧副作用无自动重发；只能用可信原对象/经单独验收的恢复证据解锁。无证据继续 unknown |
| 对外能力 | `tool_call_application.rs::execute_or_wait` 对 `run_wasm` 返回 `OperationUnsupported`；builtin 继续工作 | 旧低层 `workspace` WASM helper 不是已接入的可信生产 worker 服务 | 先验收受信内部工件与绑定，不开放公开任意 wasm 路径；公开拒绝门仅在另一个明确生产接线切片通过后变更 |

建议下一份实际任务先交“同版本 worker/Host 的独立 staging 工件 + 窄 bootstrap，不开放 run_wasm”。不升级依赖、不引入第二 owner、daemon 或安装器；失败保留旧完整配对，不能现场读取 worker 自算 hash 再宣称可信。完整生产绑定仍依赖统一执行权、持久恢复与权限矩阵各自通过，当前 runner 证据只核命令/源码/日志，不提供这些缺失证明。
