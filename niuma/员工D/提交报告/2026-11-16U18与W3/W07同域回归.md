# W07 真实 Store 绑定与监督异常回归候选

依赖组合 `5328d432` 的 A/B 能力与 Host；本提交基于 D 自有树，经理在当前窗口结束后整合为新候选。每个 case 用独立测试进程，`--exact --ignored --nocapture --test-threads=1`，固定 worker 字节/hash、独立 stage log、E 盘临时目录及原观察 handle；不得与已冻结 5328 测试结果混算。

完整名称前缀 `wasm_worker_process_tests::fault_matrix::`：

- `w07_bound_same_domain_and_cross_domain`：真实 Store/Engine 双域、固定真 worker，同域成功和进程信号/Job/I/O 证据；另一 Store 原 operation 拒绝且无新增进程阶段。
- `w07_bound_future_drop_retains_original_domain`：暂停已创建但未 resume 的真 worker，drop 原调用 future；断言原域 in-flight 及单 controller 保留、slot 未释放；释放后观察原进程信号/Job/I/O 与票据收束。
- `w07_bound_supervisor_panic_disconnect_seals_domain`：真实 Store 和原 generation，测试专用停点在创建进程之前注入线程 panic，验证 receiver disconnect 返回 CleanupUnknown，原域 sticky unknown、原票与 slot 保留并拒绝再次准入。
- `w07_bound_supervisor_panic_after_future_drop_seals_domain`：同一异常在调用 future 被丢弃后发生，验证不依赖等待方仍会封域、保留原票和 slot。

后两项故意将 slot/domain 保持 unknown 至该隔离测试进程自然退出，不创建子 worker，不得放入共享 lib 测试进程或当成需清理的现场；监督器仍须持原测试进程及其证据。每项新 attempt 单独执行且首失败/unknown 停窗。前两项确实运行固定 worker，需既有 W2 观察和 supervisor；不得在当前 manager targets 期间启动。注入 panic 只在 cfg(all(test, windows)) 存在，生产路径不启用。

静态检查：rustfmt 和 git diff --check；未运行 Cargo、测试或真实进程，未验证组合编译及通过。W07 不覆盖持久采纳或完整生产权限恢复。

## Host 关闭取消补充

绑定模式 Gate 和异步 select 同时监听 caller token 与原 operation token；前者取消不反向取消后者，原 token 来自 A 的 `cancellation_token()`，不建立新的域 owner。已知 CleanupUnknown 优先，不因同时取消被降级。新增两个 ignored exact：`wasm_worker_process_tests::fault_matrix::w07_bound_shutdown_before_resume_retains_ticket`、`wasm_worker_process_tests::fault_matrix::w07_bound_shutdown_running_retains_ticket`，通过 B 的 test_worker_operation 获取 Engine 实际 shutdown 链，调用方 token 独立；分别卡真实 worker 的 resume 前与 no-read probe 的 pending 写，调用 Engine.request_shutdown 后检验票据/slot 持有和最终 process/Job/I/O 收束。每项单独进程、固定 worker/hash 与 fresh stage；running 还需 no-read probe/hash。依赖 A/B 新接口，未运行 Cargo/真实进程。
