## 实现说明

- 公开 API：`parse_manifest`、`PluginCatalog`（`new`/`register`/`remove_descriptor`/`descriptors`/`resolve`/`scope`）、`CatalogManifestV1`、`ExactVersion`、`InterfaceKind`/`InterfaceKey`、`ScopeKind`/`ScopeKey`、`RuntimeKind`、`LifecycleKind`、`Surface`、`PluginRef`、`DependencyBinding`、`ResolutionPlan`、`CatalogError`。
- 严格 JSON：两段式——`StrictJson` 访问器对所有层级拒绝重复对象成员（`serde_json::Value` 默认静默取最后值，不符合契约），再手工提取字段以获得精确 `path` 且不回显输入值；`config_schema` 内成员名与数组下标均不进入诊断路径（内部路径恒为 `config_schema`）。
- 解析：`resolve` 仅分析 roots 传递闭包；候选按 `(kind, name)` 聚合、`version` 精确匹配；0 候选→`MissingDependency`，候选存在但版本不符→`VersionMismatch`（available 升序去重），多个精确提供者→`AmbiguousProvider`（id 升序）。拓扑用 Kahn（BTreeSet ready 按 id 升序），边 consumer→provider 去重（多接口同 provider 仅一条边）；无法全部出队时由 leftover 子图提取真实闭环路径（首尾相同、逐跳为真实边、环外节点不列入）。
- 声明面：runtime/permissions/lifecycle/config_schema 只记录不执行；无文件/网络/数据库/进程/模型访问；`remove_descriptor` 仅移除声明，不是真实卸载；`peachsh.wasm.v1` ABI 未动。
