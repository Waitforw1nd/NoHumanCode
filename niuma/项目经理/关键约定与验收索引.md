## 已知限制与非阻断事项

- 新 Turn HTTP 路由已按范围验收（待 Git 基线纳入）；完整审批/ToolCall、插件 Context/Registry/生命周期、持久 Scheduler、完整 CLI 与 Diff/Checkpoint 尚未交付；已有枚举、沙箱、工具或恢复片段不等于完整能力。
- B：MIN(seq) 不能识别只删创建事件但留后续事件；不承诺分布式恰好一次。旧 TempDir 夹具、完整表计数/空数组正例/并发副作用断言等可后续吸收加强，不重开已关闭第一轮。
- C：未来游标阈值等待与 keep-alive 缓冲消费是非阻断测试补强；参数名百分号行为按传输契约，不概括成所有未知参数都忽略。
- 已知凭据格式处理不承诺发现任意未知秘密；已有无工具 Chat 不支持伪造或裁剪工具历史来续聊。

## 更新规则

改变架构、范围或对外契约时，在当次任务/审查中记录“决定、原因、影响范围、替代的旧决定、验证与迁移要求”，再更新本索引和任务板。只是检查链接或整理目录不提高产品完成度，也不隐式重开已验收模块。
