## 策略接口

Host scope；provider ID `builtin.chat-agent`，consumer ID `builtin.engine-chat-agent`，Service `agent.strategy`，精确版本 1.0.0。PluginHost manifest、依赖、工厂、effect 和 payload 类型必须真实生效，绑定失败禁止回退内联默认逻辑。

```rust
#[derive(Clone, Copy)]
pub(crate) enum ToolClass { Read, List, Search, Write, Command, Other }
pub(crate) enum StrategyInput<'a> {
    BeforeCompletion { tools: &'a [ToolClass] },
    AfterCompletion { outcome: CompletionKind<'a> },
}
pub(crate) enum CompletionKind<'a> {
    NoToolCalls,
    ToolGroup(&'a [ToolClass]),
}
#[derive(Clone, Copy)]
pub(crate) enum ToolVote { ApplyHostPolicy, Deny }
pub(crate) enum StrategyAction {
    UseTools(Vec<usize>), ToolVotes(Vec<ToolVote>), Finish, Stop,
}
pub(crate) trait AgentStrategy: Send + Sync {
    fn decide(
        &self,
        input: StrategyInput<'_>,
        messages: &[serde_json::Value],
        round: usize,
        max_rounds: usize,
    ) -> Result<StrategyAction, StrategyError>;
}
```

StrategyError 使用不携带任意文本的固定分类，B 冻结实际枚举并先通知 C/D。round 从 0 开始，每次 run_task/resume 按原逻辑重新计数，不伪称持久会话轮次。messages 借用 Host 当前消息，Before 在原恢复对账/延后用户消息之后，After 在成功保存原 assistant 消息之后；它不是“任意秘密均已过滤”的保证。不给策略 Task、route、凭据、Store、可变消息、发送器或执行句柄。不能复制 prompt/参数/回调错误到日志或诊断。

Before 仅允许 UseTools 或 Stop。UseTools 必须严格递增、唯一、索引小于本轮 Host 工具定义数，允许空集；Host 选取原定义原顺序，不允许策略改定义。实际 Provider 请求和本轮后续工具许可都使用此子集。After 的 NoToolCalls 仅允许 Finish/Stop；ToolGroup 仅允许长度恰等原组的 ToolVotes/Stop。缺 tool_calls 与 Some([]) 不等价：后者为工具组，空投票后继续下一 round。错误阶段、越界/重复/乱序/长度错或 panic 固定安全失败，无内联回退。

builtin Before 选择全部工具；After 对无 tool_calls 返回 Finish，对原组全部 ApplyHostPolicy。每次模型调用仍消耗 Host max_rounds，调用次数由 Host 固定在每轮最多 Before/After 各一次，不允许策略驱动无界循环。现有上下文 1,500,000 字节及响应 4,000,000 字节规则保持，不为 After 静默引入更小限额。

## Host 执行与持久边界

1. Before 调用前后检查取消。Host 继续执行 Provider prepare、网络/预算 claim/send/finish 和 usage/delta 记录。After 只在成功结算并按原规则验证工具组 ID、保存原 assistant 消息后执行；策略失败不能把已发送调用改写成 NotSent 或释放未知预算。
2. 每个原工具项仍按顺序检查取消、名称、参数 JSON、是否属于本轮选中定义。Apply 走原 execute_or_wait/审批/claim/ToolRuntime；Deny 由 Host 写固定 `{"error":"blocked_by_agent_policy"}` tool-result，不创建执行批准、不执行副作用。策略不能编造结果。后项畸形时前项可能已执行，这是现有前缀语义，不能以重构名义改成整组原子拒绝。
3. Finish 仅在 Host 持久消息确为无 tool_calls 且本轮成功时返回正常结束，launch 继续决定并持久化终态。Stop 固定安全失败；若取消已发生则沿原 cancelled 路径。已创建 Run/Turn/Task 不能因运行期拒绝被声称不存在，公开创建回执也不改成同步运行结果。
4. 正常新调用尚无审批记录时，Deny 决定落盘前崩溃，恢复按原 reconcile 的 None 分支记录 interrupted 并跳过执行，不猜造原 Deny 原因；已保存拒绝结果不再次执行。已批准、已claim或unknown沿既有事实处理，不允许重策历史或自动重发。
5. 为堵住历史外孤儿审批 ID 被新组复用的恢复歧义，B 在 Store 增加小范围事务 API：同一事务校验新 assistant 工具 ID 在当前 Task 无既有审批记录，再通过原 save_task_tx 保存新消息和投影。无 schema 变化；保留现有校验、取消保护和事件规则。Engine 以候选 Task 副本保存，成功才替换运行中消息，失败不能由 launch 最终 save_task 意外写回被拒绝的工具组。该异常状态拒绝为本片明确行为，不修改正常逐项前缀执行语义；D 必须覆盖冲突、事务失败及后续终态保存。
6. 原 record_tool_result 的 event 与 save_task 是两次调用，本片不宣称二者原子或重启恰好一次。故障测试如实观察，要求不伪造成功和不执行尚无批准的拒绝项；原事务/回执是外部副作用裁决依据。

## 任务期租约、关闭与恢复

run_task 在依赖等待、running 保存、reconcile 或外部副作用之前取得非 Clone AgentLease。Run/Task 创建和 launch 登记已先发生。lease 固定策略实例并覆盖本次执行的全部轮次和审批等待，结束、失败或取消后释放。固定策略不固定权限：每次实际网络/工具准入仍重读现行 Host 授权。

acquire 只在短锁内解析活动绑定、检查 admission/generation 并增加 in-flight；全部策略/生命周期回调、析构及 await 在锁外。复用 plugin_callback 的一次安装/TLS 同步 panic 防泄露机制。可信 native 组件不构成恶意第三方沙箱，也不承诺强制中断永不返回的同步回调。

disable 在线性化锁内关新准入；有任务 lease 时保持旧实例和 effect active，显示 draining，不提前 deactivate 在途策略资源。最后 lease 释放触发锁外安全 deactivate/stop_subtree 并撤 effect。Drop 不得 panic；失败安全记录固定分类和 recovery，关闭新准入。enable 在 draining/transitioning 时返回固定 Busy；完全排空且安全撤销后才允许新代次启用，不让两个策略代次同时活跃。代次递增有溢出检查，重复同态请求不意外切代。生命周期失败不得默默恢复为可用。

run_task 新准入失败不进入 reconcile、Provider 或工具，但沿现有 launch 保存 failed/cancelled；终态保存失败仍报告 persistence_error。重启与显式 resume 重新准入，成功后先 Host 原恢复对账，再新策略；旧未知外部调用不重发。新进程默认装配 builtin，内存禁用不持久化，状态明确标 process。

Engine 提供生产 Rust enable_builtin_agent/disable_builtin_agent/builtin_agent_status；crate-private 测试注入构造器和必要停点由 B 提供并先给 C/D 准确签名，不暴露生产 HTTP 调试注入。D 不修改 B 共享文件。

## 公开只读诊断

冻结 `GET /api/runtime/agents/chat` 与 `peachsh --json runtime agent status`（human 输出同命令无 --json）。这是只读诊断，不新增写控制、schema 或 Provider 诊断，也不改变旧 files/shell PluginStatus DTO。

成功 DTO 为封闭对象：

```text
plugin_id: "builtin.chat-agent"
service: "agent.strategy"
interface_version: "1.0.0"
scope: "process"
active: bool
admission_open: bool
in_flight: u64
generation: u64
draining: bool
transitioning: bool
effects: u64
recovery: u64
last_failure: null | 固定枚举字符串
```

B 提供一致运行态快照，C 负责稳定传输 DTO/严格客户端验证。last_failure 固定白名单为 unavailable/invalid_decision/failed/panicked/stopped/busy/lifecycle/internal，不携带任意原文；无历史失败为 null，成功启用可清除旧诊断，不能把读取状态本身伪作恢复操作。transitioning 时 effects/recovery 是最后稳定快照，说明书明确。draining 表示关闭新准入且尚有任务 lease；不能显示已全部撤销。active 不等于 admission_open。

新路径显式纳入 guard authenticated_read，沿现有 token、Host、Origin、sec-fetch-site 与安全头/no-store；错误拒绝也不能泄露内部原文。新 GET 无业务参数，拒绝多余 query；非 GET/HEAD 方法不执行任何操作。无法读取时 HTTP 503、code `agent_runtime_unavailable`、retryable false，固定安全 message；沿现有错误 envelope，其余 guard/方法错误沿既有框架。CLI bootstrap 后读取，验证身份/版本/枚举/字段/计数和明确状态关系，不接受任意JSON直接打印；失败固定安全输出和 exit 1，参数错误保持 exit 2。
