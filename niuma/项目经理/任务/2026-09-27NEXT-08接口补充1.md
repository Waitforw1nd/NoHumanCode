ProjectError.code() 唯一字符串列表：

| code | HTTP状态 |
| --- | --- |
| project_invalid | 400 |
| project_not_found | 404 |
| project_revision_conflict | 409 |
| project_duplicate_root | 409 |
| project_overlapping_root | 409 |
| project_selection_required | 409 |
| project_legacy_unbound | 409 |
| project_root_changed | 409 |
| project_root_unavailable | 409 |
| project_permission_revoked | 409 |
| project_operation_unsupported | 409 |
| project_corrupt | 500 |
| project_internal | 500 |
| workspace_selection_managed | 409 |

最后一项沿原契约名称，不额外加project前缀。固定安全错误消息，不泄漏底层路径/密钥/SQL。选择与配置CAS均使用project_revision_conflict，由endpoint识别对象。

NetworkErrorKind若新增对应项目拒绝变体，其serde snake_case名与上表code一致；B提供 `project_code(&self)->Option<&'static str>`，项目变体返回Some，原网络变体返回None。C先映射项目code/status，再处理原网络种类；任何分支均保持NetworkError的dispatch_state/calls，check部分已发送证据不能丢失。不是把网络结果转换成普通无回执的ProjectError。

Engine::project_runs(&ProjectId)按原列表语义 created_at降序、最多100。C将返回Vec<Run>投影成原runs四字段summary数组，不能因为加project筛选便泄露/扩大成完整Task消息数组。未知project返回project_not_found，不用空数组混淆。

本补充只有接口精确化，无新增产品测试结果。源码所有权与验收矩阵仍按契约1.0和正式任务包。
