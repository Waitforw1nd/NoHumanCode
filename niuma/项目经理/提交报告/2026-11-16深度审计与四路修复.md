## 缺陷与修复

| 问题 | 触发与处理 | 验收边界 |
| --- | --- | --- |
| P1 流式分片绕过脱敏 | token、Bearer、敏感赋值跨 delta 时，事件逐条过滤无法识别。过滤必须位于可替换 codec 之外的 Host 输出边界，并保留跨片状态 | 正常 Unicode、有界状态、错误/取消、Store 与 SSE；启发式规则不识别任意未知秘密 |
| P1 跨 completion 重组 | Engine 连续工具轮次直接拼接 delta，单个 completion 结束清空状态不足；双层过滤又会先丢失敏感字段身份 | 必须在原始 decoder 输出边界沿用 task 状态；只最终成功释放未确定尾部 |
| P1 关闭缺少后台等待 | 原 task JoinHandle 被丢弃，且审批写入失败可阻断取消 | 关闭准入、无条件取消、持有并等待原 worker；超时不 abort 后宣称成功；资源 unknown 与写库成功分别处理 |
| P2 跟进输入重启丢失 | 待闭合工具组的跟进只在内存 map，移出 map 后写库失败也可丢失 | 版本化 pending resume 事件、消息与消费标记同事务；旧无版本事件不猜测重放；schema 保持17 |
| P2 时钟回退改变文件恢复顺序 | created_at 排序混淆同一路径最早 before 与最后 after | 按持久插入顺序；验证旧 checkpoint 原摘要和条目，不改写旧 manifest；无法对应因果内容的旧恢复明确冲突 |
| P2 Windows 短名绕过策略 | caller 拼写通过但真实路径属于敏感文件/目录或另一声明写范围 | 逐级真实路径策略，最终真实写范围复核；真实 NTFS 合成别名负控与正控 |
| P2 输出上限冒充 EOF | reader 到64 KiB即关闭，可能损坏命令或提前判断管道完成 | 持续排空并仅保存每流前64 KiB；超限后错误传播、真实 EOF 和有界 Shell 验证 |
| P2 分发错误 EXE | Cargo 自定义 target 目录时脚本仍复制默认旧产物 | 从本次 Cargo artifact 消息选 Host；缺失/歧义/失败不覆盖原发布文件 |
| 验证入口缺失 | 网页行为回归未进入日常门禁，minimal 工具链未声明格式/Clippy | test 接网页验证，提供独立入口，声明 rustfmt/clippy |
