
# NoHumanCode 项目经理：项目记录说明

现行位置：`./niuma\项目经理\项目记录`。原根目录 records 已迁移；经理从 [个人身份认知](../个人身份认知.md) 开工，所有人员从 [协作中心](../../README.md) 查找自己的档案。

本目录保存两种记录：

- `CONVERSATION-FULL.md`：可见的用户消息、助手回复和工具动作元数据，按轮次追加。
- `PROJECT-PROGRESS-SUMMARY.md`：项目进度、决策、风险、下一步和模型自我述职。

记录原则：

1. 每轮对话结束时同时更新两个文件。
2. 全量记录不保存隐藏推理。
3. 工具输出先脱敏，再决定是否记录；不记录真实 Key、令牌或凭据。
4. 摘要记录当前事实，不把计划写成已完成。
5. 新窗口开始工作时先读取根 AGENTS.md、本人身份与摘要，再按需读取任务、最新 review、全量记录和项目书。
6. 2026-09-23 迁移前的对话正文按原样保留。旧名称、旧文件位置与旧判断是历史记录；通过经理审查目录中的迁移清单定位新路径，不能据此重建旧目录或执行旧任务。
