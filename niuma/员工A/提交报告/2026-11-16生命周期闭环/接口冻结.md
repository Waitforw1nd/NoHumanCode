## B 可立即接线

- `DomainLease: Send + Sync + 'static`：`seal_unknown(&mut self)` 同步封新准入，不可重入/恐慌；`settle(self: Box<Self>)` 一次消费真实票，可阻塞，不得重开已封准入。
- `ProcessSpec::new(program, cwd, complete_environment, (stdout_limit, stderr_limit), overflow, absolute_deadline, cleanup_budget)`；`args` 为 `Vec<OsString>`。预算非零且不超过五秒。保留调用者既有授权/参数/env/限流策略。
- 同 controller Shell/Git/diff 共用 `Supervisor::new(NonZeroUsize)`；保存配置后更新原对象 `resize(&self, NonZeroUsize)`，不重建。
- `submit(&self, ProcessSpec, Box<dyn DomainLease>) -> Result<Operation, NotStarted>`。同步拒绝的 `NotStarted { reason, lease }` 返回原 lease，调用者负责消费结算；旧实际方法名是 submit。
- `Operation::cancel(&self)` 只请求停止；`wait(self)` 返回 `Outcome::{NotStarted {stage, os_error}, Settled(Settled), Unknown}`。Settled 包含 reason/identity/exit_code/stdout/stderr。异步 NotStarted/Settled 的 lease 已由组件结算；Unknown 先封门，holder 后台保票和原对象，迟到清理不改业务 unknown。
- 经经理新增授权，`wait_with_cancel(self, &tokio_util::sync::CancellationToken)` 保持同一 pinned wait；token 取消只请求原 holder 停止，继续等待同一终态。B 的 Shell/Git/diff 应用此方法，不能 select 丢弃 wait 后把取消当结算。
- Git 整项票由 B 持有，子进程 adapter 只结算顺序代次，不能首个子进程完成即释放整项票。
