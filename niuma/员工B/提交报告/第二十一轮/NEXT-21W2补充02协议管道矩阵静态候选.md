- `wasm_worker_process_tests::fault_matrix::w02_protocol_fault_matrix`：合法正控；长度头 1/2/3 字节、声明比完整合法 JSON 多一字节的截断 payload、零/超长、UTF-8/JSON/未知/重复字段、尾字节/第二帧；九个 manifest 字段逐一修改；阶段/索引/重复及逆序/票数；合法 Error、带输出和无输出 exit42；合法帧或超长前缀保持打开、迟于截止发送计划。精确断言 Protocol、WorkerRejected、worker_exit42 或 Deadline。
- `wasm_worker_process_tests::fault_matrix::w03_pipe_fault_matrix`：真实 Win32 stdout/stderr 零写及后续字节、stdout 和 stderr 各自越限、近 8 MiB stdin 无读及读 32 字节后关闭、部分 stdout 保持打开、stdout 关闭但 stderr/进程仍活、非读取 stdin 时两路输出，以及双路压力。部分读使用 sidecar 屏障等待 Host 记录 stdin pending；双压力由独立写线程发起两路各 128 KiB，测试态暂停读取，实际查询两路管道容量与可读字节，均达到容量且 stdin pending 后恢复读取，期望唯一 stderr_limit；达不到三秒停点则报告失败，不假设固定容量。

R06 两个场景分别打印实际是否观察到 stdout/stderr 零读；真实零写和后续字节本身不能证明 Host 零读分支命中。没有加入确定性零读注入；若本机未观察到零读，该分支动态覆盖仍开放。迟发场景只要求进程在等待迟发时到达截止，不能声称被终止的进程实际完成迟发。
