# NEXT-01 联合验收矩阵

日期：2026-09-23；修订1；负责人：员工 C（用户分发后）；审查人：项目经理。当前均为待员工实现与验证，不是本轮已通过清单。范围以 [任务契约](新增Turn-HTTP契约.md) 为准。

## 夹具与证据共同要求

- 联合测试新增到 `NoManCode/rust-app/tests/turn_http.rs`，通过实际 loopback HTTP server 与本机 mock Provider 访问路由；不得把直接调用 Engine 当作新 POST 已验证。专用错误 mapper 的穷尽分类允许在 server 模块内做单测，并与 HTTP 证据区分。
- 首轮正常夹具从真实 `POST /api/runs` 建立无工具 Chat，使用存在的临时 workspace、匹配的 settings/route 和 mock，等首轮真正 completed 后取得 Session、Agent、前序 Turn。现有 http_contract 的 `seed_chat` 使用伪路径/不可调用 route，只适合其原读测试，不能原样用于本轮追加。
- 在每个错误夹具中先证明基准可追加，再仅注入目标故障。记录首轮 Provider 调用基数，断言的是新增调用差值；不能把总调用 2 误判为新消息调用两次。并发 mock 通过保存 permit 的通知/通道或 Barrier 同步，不靠长 sleep 制造时序。
- 无写入副作用至少检查11张表：projects、sessions、turns、agents、turn_tasks、turn_task_dependencies、idempotency_records、runs、tasks、idempotency、events。静止夹具保存计数和相关行内容/事件最大 seq，失败后均不变；只数行不能证明旧行未被改写。
- 活跃任务可正常产生 delta/status 事件，因此忙状态或并发测试应阻停 mock，在明确阶段比较候选对象/幂等记录和调用数，区分原任务合法事件与被拒命令副作用，不机械要求整库永久静止。
- 故障测试先注入并确认目标故障，再在发送待拒请求之前建立副作用快照；注入本身的变化不算命令副作用。N11的第二个Engine不得对仍在运行的共享库调用recover，恢复仅用于N16真正停止旧Runtime之后。
- SSE 测试使用同一个 Response 与增量缓冲，确认已读普通事件后才断开或注入故障；检查 JSON envelope 与 SSE id，并对每次等待设界限。重启夹具 TempDir 在两个 Runtime 外持有，确认旧 Runtime/任务已停止，不能仅 drop 外部 Harness。

## 必须交付的场景

| --- | --- | --- |
| N01 正常追加 | 完成首轮后 POST；再完成新增轮并追加下一轮 | 首次201/replayed=false；每轮独立准确 Turn/Task；Project/Session/Agent/Run 数不增，Turn/TurnTask/legacy Task 各+1，前序内容不变；两种幂等表记录对应同一新命令；每条新消息 Provider +1 |
| N02 查询/SSE一致 | 从首轮游标订阅 Session，POST新轮并释放 mock | 回执、GET turns/turn、SSE 的 session_id/turn_id/task_id 对应；SSE id=seq，重连仅更大seq，允许全局间隔；不返回 Run 首任务 |
| N03 重复/稳定语义 | 同 key 同请求运行中重试、完成后重试，JSON字段换序/等价转义；再产生更后轮后回放旧请求 | 每次200/replayed=true、原Turn/Task身份不变；该消息只执行一次、无新增对象/幂等项；最新前序已变化也可回放；状态字段允许更新 |
| N04 冲突 | 同 key 分别仅改变 message、agent、session、前序；另复用首轮 Run key | 409/conflict/false、固定安全错误；无该请求写入/Provider调用；请求仍须格式合法，身份变更尽量选已有合法对象以证实冲突先于资格检查 |
| N05 严格输入 | 单故障：缺字段/null/非字符串/重复字段/未知字段/body session_id或key；无效path UTF-8；各ID空白、控制、超128字节、已知敏感标识 | 400/request_failed/false、error=message、安全头；无副作用，原消息/敏感输入不回显；非UUID合法ID规则不被误收紧 |
| N06 key边界 | 缺头、重复同值/异值、逗号合并、空白、非ASCII、201字节、已知敏感值；200字节普通key正例 | 非法400，合法200字节新请求201且可200回放；header名大小写等价；不用body/query补头，不trim/解码 |
| N07 消息/体积 | 空白消息；100000/100001 UTF-8字节；多字节边界；短新消息但累计JSON>1500000；无/错Content-Type、畸形JSON、body>1MiB | 消息或累计超限400，媒体415，body413；边界正例可追加；原始message进入mock/摘要（应用既有持久化脱敏另按原规则），不擅自trim；每个反例只因目标条件失败 |
| N08 安全门 | 错Host、错Origin、cross-site、缺/错写token，每次body本来合法 | 403/forbidden/false与三项安全头，无新行/模型调用；合法写成功也有安全头；旧安全契约不放宽 |
| N09 缺失/不支持 | 分别不存在Session/Agent/前序；已有跨Session Agent/Turn、Team/多Agent、带工具权限/工具历史 | typed缺失404；不支持400；不伪造或裁剪历史；非空、非数组tool_calls及role=tool拒绝，空数组允许；每例无副作用且错误不是无关FK/路由失败 |
| N10 前序/忙 | 已有后继后用新key提交旧前序；最新Turn或其Task确实非completed（running、cancelled、interrupted等合法状态） | stale/busy为409/conflict/false，无新任务/调用；不能把传输成功当执行完成。前序changed的mapper也必须覆盖 |
| N11 同key竞争 | 两个HTTP请求同时发；至少一个测试用独立Engine/Store连接指向同一临时DB，验证不是单Engine gate串行掩盖 | 一个201，一个200；准确同Turn/Task；新消息Provider差值1；新Turn/TurnTask/legacy Task/两类幂等各只一组；该新Turn/Task的kind=status且data.status=queued事件恰好一条，后续running/终态事件正常出现 |
| N12 异key竞争 | 两个请求同前序，不同合法key，屏障同时放行 | 恰好一个201、另一个409（按实际命中的typed冲突）；仅胜者新增一组对象/幂等及调用；失败key可在读取最新已完成前序后重新作为新命令使用 |
| N13 损坏/内部故障 | 有效静止库分别注入Session/Agent/Turn负时间；保留Turn/Task与身份关系但删除一个既有Turn全部所属events以缺失顺序证据；legacy tasks.value非法JSON；触发器拒绝首事件插入 | 500/internal/false，不能400/404；以故障注入后快照验证请求失败不改11表及相关旧行、不调用Provider；事件插入失败必须整笔回滚；错误不泄露人工植入的SQL/路径/请求哨兵。跨Session归属不符按N09的UnsupportedSession=400，不混作本例 |
| N14 配置与回放次序 | 有效前缀仅删除route/移除凭据或改变URL；另在已成功命令后移除route再回放同key | 新命令安全500/internal/false且无副作用；已提交同key仍200回放，不查key、不重新执行；报告明确当前配置错误无typed分类 |
| N15 断线 | 新POST后 mock 已进入running并发出至少一个持久delta，SSE真读到后关闭该订阅 | 后台仍运行；释放mock后完成；该新消息调用总差值1；同key200回放，重连大于最后游标、归属正确 |
| N16 重启 | 真实分块partial已落库后停止拥有任务的Runtime；同库重开并recover再开HTTP | Task/Turn按既有恢复契约 interrupted、partial保留；同key POST200回放同身份、Provider不增、未自动busy；显式resume的既有语义不被改变 |
| N17 兼容与映射 | 跑原有测试集合；server局部单测覆盖全部ChatTurnError、IdempotencyConflict、带context的错误、busy/locked、原始缺行/普通anyhow | 原GET/Run/Task/SSE成功与错误保持；映射按契约穷尽，busy/locked500且true，其余未知安全500。PredecessorChanged可用typed mapper单测+B原事务正式用例证明，不要求给Engine新增测试钩子 |

N17 的映射单测不能冒充真实 HTTP 故障；N13/N14 必须真实 HTTP。可复用既有 B 对前序快照竞争的有效正式回归，报告明确哪部分是继承证据、哪部分为本轮新跑；不为穿透窄时间窗而扩大 Engine 所有权。
