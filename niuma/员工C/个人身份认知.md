## 历史教训与非阻断项

- query 参数名须严格解码后识别；编码后的重复、非法 after 不能退回 0。query/header 都合法后才按优先级选取。
- 框架 Path/JSON 提取错误也要进入结构化错误契约；已进入纯存储读取边界的内部故障安全返回 500，保持真正不存在与业务校验的区别。
- SSE builder 前校验 kind；成功构帧后才推进已发游标，故障一条 error 后 EOF，不生成业务事件。
- 长连接测试保留同一 Response 与缓冲，先真实读到帧再注入故障。断线夹具必须真 running，交错/未来游标必须先断言前置条件。
- 单次握手采用保存 permit 的 notify_one 或等价通道；固定先通知后等待，不能靠长 sleep 或删除断言规避竞态。
- 非阻断后续：未来游标阈值处单独观察 HTTP 等待；keep-alive 测试读帧器完整消耗缓冲注释帧。解码后名称仍含字面百分号的拒绝策略以契约为准，不概括成所有未知参数均忽略。
- B 并行中间态曾阻塞全量测试，须按当时快照如实记录；不越权替 B 修复，也不把独立 HTTP 通过写成全仓通过。
